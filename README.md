## Descripción
Aplicación de escritorio en Java que implementa un TDA para el registro de mascotas (gatos). Aplica los conceptos de:
- Tipos de Datos Abstractos (TDA)
- Encapsulamiento
- Herencia
- Recursividad
- Interfaz Gráfica de Usuario (GUI)

## Tecnologías utilizadas
- Java 21
- NetBeans
- Swing (GUI)

## Cómo ejecutar
1. Abrir el proyecto en NetBeans.
2. Ejecutar el archivo `VentanaPrincipal.java`.

## Funcionalidades
- Registrar un gato (nombre, peso, raza, edad).
- Calcular dosis de medicina diaria.
- Calcular dosis para varios días (método recursivo).
- Calcular edad humana del gato.
- Determinar si el gato es senior.
